# RPG Game

Простая RPG-игра, созданная с использованием библиотеки Pygame.

## Описание

Это проект игры в жанре RPG (Role-Playing Game), где вы можете управлять персонажем и исследовать игровой мир.

## Требования

- Python 3.x
- Pygame >= 2.6.0

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd M9L1
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Запуск игры

```bash
python main.py
```
